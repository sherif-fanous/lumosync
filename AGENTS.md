# Agents

- [mise](https://mise.jdx.dev/) is the task runner and provisions Node. See
  `mise.toml` for the full list. `mise run check` is the pre-commit gate;
  `mise run format` and `mise run lint-fix` fix most of what it reports.
- Apply the `humanizer` and `unslop` skills to documentation, comments, and
  user-facing strings.
- Start each source file with a short module JSDoc. Document exported
  functions, types, and constants with short JSDoc blocks.
